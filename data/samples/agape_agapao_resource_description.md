# Biblical Lexical Sample – Agapē / Agapaō

## What This Resource Does

This JSON provides a structured, multi-source lexical profile for the Greek words **ἀγάπη** (*agapē*, G26) and **ἀγαπάω** (*agapaō*, G25). It is designed to support careful word study by making the following tasks straightforward:

- Identify which original Greek word stands behind an English translation of “love” (especially when multiple instances appear in the same verse).
- Compare definitions and emphases across major traditional lexical and concordance resources.
- See frequency, related words, common morphological forms, and key theological uses at a glance.
- Examine the distinction between *agapaō* and *phileō*, particularly in John 21:15–17.
- Review Septuagint (LXX) background and how the words were used to translate the Hebrew root **אָהַב** (*ʾāhab*) and noun **אַהֲבָה** (*ʾahăbâ*).
- Track translation choices (especially the KJV’s use of “charity” versus modern “love”).
- Access selected occurrence examples and detailed verse-level mappings for important passages (John 3:16 and John 21:15–17).

The data is organized so that an application or study tool can present lexicon entries, contrasts, morphology, LXX background, and verse-level analysis in a consistent, machine-readable format. The same structure can be extended to other Greek or Hebrew words.

## Sources Used in the JSON

The entries draw on the following primary resources:

| Source | Contribution |
|--------|--------------|
| **Strong’s Exhaustive Concordance** (Greek & Hebrew) | Numbering system (G25, G26 and corresponding Hebrew numbers), basic glosses, part of speech, derivation notes, and KJV translation counts. Used for both the Greek entries and the Hebrew background (אָהַב / אַהֲבָה). |
| **Young’s Analytical Concordance** | Grouping of English words by underlying Greek original and literal-meaning orientation |
| **Bullinger’s Critical Lexicon and Companion Bible** (especially Appendix 135) | Emphasis on self-denying, devoted love; notes on Johannine usage and the *agapaō* / *phileō* distinction |
| **Thayer’s Greek-English Lexicon of the New Testament** | Fuller definitions, range of usage (divine, human, Christian love), and classical observations for the Greek terms |

**Note on Hebrew sources**  
For the Hebrew background linked to the LXX usage of *agapaō* / *agapē*, this resource uses **Strong’s Hebrew Dictionary** rather than a fuller lexicon such as Brown-Driver-Briggs (BDB). Strong’s provides concise, consistent glosses and numbering that align with the Greek Strong’s system already in use.

Additional layers in the JSON (frequency notes, morphological forms, LXX summary and selected examples, translation-variant history, semantic contrasts, etymology notes, and theological highlights) synthesize information commonly derived from these sources together with standard New Testament and Septuagint usage data.

## Scope Notes

- Occurrence lists and LXX examples are **representative samples**, not exhaustive concordances.
- The resource focuses on traditional lexical tools frequently used in English-speaking Bible study.
- The structure is intentionally reusable: the same pattern of fields can be applied to other Greek or Hebrew terms.
