# Raw source texts

Source files go here, one folder per source, exactly as downloaded. Nothing in this folder is edited by hand.

Expected, and tracked in [`SOURCES.md`](../../SOURCES.md):

- `bullinger/`: Bullinger, *A Critical Lexicon and Concordance* (5th ed., 1908). `ocr/` holds the OCR of every page; see its README.
- `youngs/`: Young's Analytical Concordance. Only the pages needed are OCR'd (see SOURCES.md); the scan is too large for the repo.
